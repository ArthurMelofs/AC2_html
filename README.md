O objetivo é criar um sistema web utilizando apenas HTML, CSS e JavaScript, sem a utilização de back-end ou banco de dados.

O site permite navegar por diferentes modalidades esportivas, visualizar notícias, consultar um calendário de eventos e adicionar esportes aos favoritos.

Tecnologias utilizadas

HTML5: estrutura das páginas.

CSS3: estilização e responsividade.

JavaScript: funcionalidades e interações do site.

LocalStorage: armazenamento dos esportes favoritos no navegador.

Funcionalidades

O projeto possui cinco páginas principais:

Início: apresentação do site e destaques esportivos.

Esportes: informações sobre futebol, basquete, vôlei e tênis.

Notícias: notícias demonstrativas com filtro por modalidade.

Calendário: exibição de partidas e eventos esportivos fictícios.

Favoritos: opção de adicionar e remover esportes favoritos.

Como executar

Baixe ou clone o projeto.

Abra a pasta SportsZone.

Execute o arquivo index.html em um navegador.

Utilize o menu para navegar pelas páginas.

Não é necessário instalar nenhuma dependência.
